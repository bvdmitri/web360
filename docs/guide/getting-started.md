# Getting started

Install the package from npm:

```sh
npm install @bvdmitri/web360
```

It runs in a browser with WebGPU and WebCodecs, best in a dedicated Web Worker, and hands you
`VideoFrame`s to encode: playback, audio and storage stay with your application. The
[API reference](../api/) lists every export.
